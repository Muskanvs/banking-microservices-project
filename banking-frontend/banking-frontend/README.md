# Banking Microservices Frontend

React + Vite dashboard designed against the controllers/DTOs in the supplied bankingproject ZIP.

## Requirements
- Node.js 20.19+ or 22.12+ recommended (current Vite releases requirement)
- API Gateway running on `http://localhost:8080`
- Account service, Transaction service, Payment service and their dependencies running as needed

## Run locally
```bash
npm install
npm run dev
```
Open the URL Vite prints (usually `http://localhost:5173`).

The default API base URL is `http://localhost:8080`. You can change it from the dashboard's **API connection** control. For a deployment build, create `.env.production` with:
```env
VITE_API_BASE_URL=https://YOUR-PUBLIC-GATEWAY-URL
```
Then run `npm run build`. Do not put database passwords, Razorpay secrets, or webhook secrets in frontend environment variables; Vite variables are public in the browser bundle.

## Endpoints used
- `POST /api/v1/accounts`
- `GET /api/v1/accounts/{accountNumber}`
- `GET /api/v1/accounts/{accountNumber}/balance`
- `POST /api/v1/transactions/transfer`
- `GET /api/v1/transactions/{transactionId}`
- `GET /api/v1/transactions/account/{accountNumber}`
- `POST /api/v1/transactions/{transactionId}/verify?otp=...`
- `POST /api/v1/payments/create-order`

## Important boundaries
- UI uses real API calls and does not display fabricated account/transaction records.
- Payment screen calls your current create-order endpoint. It does not implement Razorpay Checkout or claim a payment is complete.
- OTP is not generated by the UI. Use the OTP from the backend's configured flow/logs/notification path.
- Demo UI is not production banking software; do not use real customer data or credentials.
